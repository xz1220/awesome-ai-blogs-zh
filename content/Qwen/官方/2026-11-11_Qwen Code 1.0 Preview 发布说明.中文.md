Qwen Code 1.0 Preview 现已发布。在 Preview 阶段，部分接口、配置选项和行为可能会发生变化。

## 亮点

- 融合了 Qoder 与 Qwen Code 的智能体能力，覆盖代码理解、实现、调试与测试。
- 支持 Qwen 和 Qoder 账号、多个模型提供商，以及自定义兼容端点。
- 提供 macOS、Linux 和 Windows 的原生安装包，无需单独安装 Node.js。
- 支持会话恢复与非交互式执行，适用于持续开发、脚本编写和自动化场景。
